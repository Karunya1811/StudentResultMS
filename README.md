# Student Result Management System

A console-based Java application to manage student academic records.

## Features
- Add new students with marks
- View all students and grades
- Search student by ID
- Delete student records
- Automatic grade calculation (O, A+, A, B+, B, C, F)

## Technologies Used
- Java (Core Java, OOP)
- Collections Framework (ArrayList)
- Eclipse IDE

## OOP Concepts Used
- Encapsulation (private fields, getters)
- Object instantiation and constructors
- Method design and modularity

## How to Run
1. Clone this repository
2. Open in Eclipse IDE
3. Run MainApp.java
